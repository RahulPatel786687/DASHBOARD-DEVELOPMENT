*DESCRIPTION*:
This project is an interactive Sales Dashboard developed using Power BI to analyze and visualize Amazon sales data. The dashboard provides valuable business insights by transforming raw sales data into meaningful visual reports and analytics.

The main objective of this project is to perform sales analysis and help understand business performance through data visualization techniques. The dashboard presents key metrics such as total sales, profit, quantity sold, product categories, customer segments, and regional performance in a clear and interactive manner.

The project includes data cleaning, preprocessing, and transformation before creating visualizations in Power BI. Multiple charts, graphs, KPI cards, and slicers are used to make the dashboard user-friendly and interactive. Users can filter the data based on categories, regions, products, or time periods for detailed analysis.

Key features of the dashboard include:

Total Sales and Profit Analysis
Product Category Performance
Region-wise and State-wise Sales Insights
Monthly and Yearly Sales Trends
Customer Segment Analysis
Interactive Filters and Slicers
Business Performance Visualization
